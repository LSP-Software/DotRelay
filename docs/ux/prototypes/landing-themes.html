Share environment variables with your team.

DotRelay keeps your .env values in one place and gets them onto every machine that needs them. Values are encrypted before they leave your computer.

How it works

Set it up once per repository. After that, it's one command to share a change and one to get it.

  1. Add your repository

    Run this in your project folder. It creates the project and a development environment.

    dotrelay init

  2. Push your .env

    Uploads your values, encrypted. Each push is saved as a new revision.

    dotrelay push

  3. Pull on any machine

    Teammates and your other computers get the same values in their .env.

    dotrelay pull

What you can do

Keep every machine in sync

Development, staging and production each have their own values. Pull whichever one you need.

Undo a bad change

See who changed what and when. Roll back to any earlier revision from the terminal or the browser.

Keep some values to yourself

Mark a variable as personal, like a local database password. Everyone sets their own value.

Use the terminal or the browser

Edit values, invite teammates and review history on the web. Everything also works from the CLI.

The server can't read your values

Encryption happens on your computer. The server only stores and passes on encrypted data.

Signing in with GitHub only tells DotRelay who you are. It doesn't give anyone access to your values.

DotRelay uses standard cryptography (X25519, Ed25519, AES-256-GCM). It isn't designed to resist quantum computers.

Questions

How much does it cost?

Nothing during the private alpha. DotRelay is open source under AGPL-3.0, so you can also run your own server.

What happens if I lose my laptop?

Revoke it from another device or the browser so it can't get new changes. To get back in on a new machine, approve it from a device you still have, or use the recovery code you saved when you set up.

What if I lose every device and my recovery code?

Your values can't be recovered. Nobody, including us, has a copy we can decrypt. That's why we ask you to save a recovery code when you set up.

What happens when I remove someone from the team?

They can't get any new changes. Anything they already pulled is still on their machine, so change those values afterwards.

Can I run DotRelay on my own server?

Yes. The server and CLI are open source. Point the CLI at your server with dotrelay setup https://your-server.

Try it on one repository

Install the CLI, run dotrelay init in a repository, then push.
